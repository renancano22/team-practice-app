# Team Practice App

A tiny Node.js app for practicing Git, GitHub, and Vercel. No packages to install.

## Run it locally

```bash
node server.js
```

Then open http://localhost:3000. Press `Ctrl + C` in the terminal to stop it.

## Project structure

```
public/index.html   the web page (what developers usually edit)
api/hello.js        the Node.js backend function (/api/hello)
server.js           local-only server, Vercel does not use it
package.json        project info
```
